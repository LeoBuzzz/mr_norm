# Baseline

Запущен `run_baseline.py` по согласованным примерам.

Результат: **9/15 рабочих проверок проходят**; один случай (`методуказания по проектированию`) помечен как gap каталога.

## Ошибки текущей реализации

1. `постановление правительства 86` — не найдено; номер 86 не извлекается из этой формы.
2. `приказ 903н` — конфликт/ложная кандидата; суффикс `н` не поддержан надёжно.
3. `правила вывода в ремонт` — не найдено, хотя запись есть в каталоге.
4. `правила ОТ` — ложное совпадение с другим документом.
5. `ПТЭ` — выбирается ПТЭ потребителей вместо приказа № 1070.
6. `методуказания по устойчивости` — выбираются правила оперативно-диспетчерского управления вместо приказа № 630.

## Приоритеты исправления

1. Канонический номер и вид акта имеют приоритет над fuzzy/topic matching.
2. Точный alias из согласованного реестра имеет приоритет над общим сходством.
3. Для коротких неоднозначных аббревиатур нужен явный alias с конкретным `doc_id`.
4. При конфликте вида/номера результат должен быть `ambiguous`, а не случайный документ.
5. Отсутствующие в каталоге документы, включая приказ № 1286, сначала добавляются в канонический каталог.
