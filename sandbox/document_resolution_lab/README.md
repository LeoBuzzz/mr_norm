# Document resolution lab

Песочница для исследования и доведения до идеала распознавания нормативного документа в пользовательском запросе и применения фильтра поиска по документу.

## Правила

- Рабочая реализация проекта не изменяется до согласования таблицы соответствий коротких названий документам.
- Все эксперименты, отчёты и fixtures хранятся внутри этой директории.
- Источник истины для соответствий — каталог документов и канонический `doc_id`.
- Локальная модель/LLM используется только как вспомогательный кандидат; финальное решение проверяется детерминированными правилами.

## Первый этап

Подготовить таблицу `короткое название → документ → doc_id → основание/неопределённость` для согласования пользователем.
