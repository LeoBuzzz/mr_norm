# Форма добавления коротких названий документов

Заполняйте одну строку на один документ. Если у одного документа несколько независимых групп коротких названий, можно добавить несколько строк с тем же `doc_id`.

## Как заполнять

- `doc_id` и полное название берите из каталога документов.
- В поле «Короткие названия» указывайте естественные формулировки, которыми вы реально пользуетесь.
- В поле «Варианты написания» добавляйте сокращения, падежи, перестановки слов, дефисы и формы с номером.
- Не добавляйте слишком общие слова вроде «правила», «инструкция» или «методика» без уточняющего контекста.
- Если название может означать несколько документов, укажите это в поле «Неоднозначность».
- Для уже подтверждённых строк поставьте статус `согласовано`.

## Короткий вариант для сообщения в чате

Можно присылать данные блоками:

```text
Документ:
Номер и вид акта:
doc_id:
Короткие названия:
Варианты написания:
Примеры запросов:
Неоднозначность:
Статус: новый / согласовано / требует уточнения
```

## Пример заполнения

```text
Документ: Правила технической эксплуатации электрических станций и сетей Российской Федерации
Номер и вид акта: приказ Минэнерго № 1070
doc_id: doc_eae0520bf60a818d
Короткие названия: ПТЭ
Варианты написания: ПТЭ электростанций, ПТЭ станций и сетей, правила технической эксплуатации станций
Примеры запросов: что говорит ПТЭ о проверке оборудования
Неоднозначность: не смешивать с ПТЭ потребителей, приказ № 811
Статус: согласовано
```
